# Task 3: Retail Sales Forecasting

## Project Overview
This project uses historical retail sales data to predict sales using a Random Forest Regression model.

## Tools Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Power BI

## Methodology
- Cleaned and preprocessed historical sales data.
- Created date-based features.
- Trained a Random Forest Regression model.
- Evaluated performance using MAE, RMSE, and R².
- Visualized actual vs predicted sales and generated a 30-day forecast.

## Model Results
- MAE: 6.57
- RMSE: 8.29
- R² Score: 0.8811

## Deliverables
- Python notebook
- Power BI dashboard
- Actual vs predicted sales CSV
- 30-day forecast CSV
- Feature importance CSV

## Forecast Assumption
The future forecast assumes no promotion and no holiday for the forecast dates.

## Note
Forecasts are model-based estimates and may differ from actual future sales.
