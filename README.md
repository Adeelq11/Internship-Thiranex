## Task 2: Customer Segmentation Project

### Project Title
**Customer Segmentation Using RFM Analysis & K-Means Clustering**

### Project Overview
This project focuses on customer segmentation using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering.

The objective was to analyze customer purchasing behavior and identify meaningful customer segments that can help businesses develop targeted marketing and customer retention strategies.

### Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Power BI
- CSV

### Dataset
The dataset contains **25,000 customer sessions** and **29 columns** covering customer visits, purchases, revenue, products, marketing channels, and other session-related information.

After calculating RFM metrics, **8,442 unique customers** were identified. Customers with at least one recorded purchase were selected for clustering, resulting in **4,176 customers** for the final segmentation analysis.

### Methodology

1. Loaded and prepared the customer dataset using Pandas.
2. Converted the visit date into the correct date format.
3. Calculated RFM metrics:
   - **Recency:** Days since the customer's last recorded visit.
   - **Frequency:** Number of recorded purchases.
   - **Monetary:** Total revenue generated by the customer.
4. Filtered customers with at least one purchase.
5. Standardized RFM features using `StandardScaler`.
6. Used the Elbow Method to determine the number of clusters.
7. Applied K-Means clustering with **5 clusters**.
8. Assigned meaningful business segment names to the clusters.
9. Created visualizations using Matplotlib.
10. Built an interactive Power BI dashboard for customer segmentation analysis.

### Key Business Insights

- **Champions:** 346 customers show high purchase frequency and high spending.
- **At Risk Customers:** 778 customers have the highest average recency and may require re-engagement campaigns.
- **Loyal Customers:** 753 customers demonstrate repeat purchasing behavior and can be targeted with loyalty offers.
- **New / Occasional Customers:** 1,708 customers can be targeted with personalized offers to encourage repeat purchases.
- **High-Value New Customers:** 591 customers have strong spending potential and can be converted into loyal customers.
