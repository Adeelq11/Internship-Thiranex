# Samsung Smartphone Sales & Revenue Analysis Dashboard

## Project Overview

This project is a Power BI dashboard designed to analyze Samsung smartphone sales and revenue performance.

The dashboard provides insights into:
- Total units sold
- Total revenue
- Average revenue per unit
- Average market share
- Revenue trends by year
- Top-performing smartphone models
- Regional revenue performance
- 5G vs Non-5G performance

## Tools & Technologies

- Power BI
- Microsoft Excel
- CSV Dataset
- DAX
- Data Cleaning
- Data Visualization

## Dashboard Features

- Interactive Year filter
- Region filter
- 5G Capability filter
- KPI cards
- Revenue trend analysis
- Top 5 product analysis
- Regional performance analysis
- 5G vs Non-5G comparison

## Key KPIs

- Total Units Sold
- Total Revenue
- Average Revenue per Unit
- Average Market Share

## Dataset

The dataset used in this project is a public/community dataset and is not official internal Samsung company data.

## Project Outcome

The dashboard demonstrates practical skills in data cleaning, KPI tracking, data visualization, interactive dashboard development, and business insight generation.
